# 004. Built-in characters from a modular pixel rig, art by code

- Status: Accepted
- Date: 2026-11-22

## Context
v1 ships 10 original characters (SPEC §5.3). Each needs ~20 shared animations plus 3–5 signature ones, about 200 in total. Drawing them one by one is not realistic for a solo developer. Lesson from Cossack Kin: its first prototype failed because the art was judged too simple, so the art gate comes first.

## Decision
- **Rig:** a shared skeleton (frame 48×48 or 64×64, fixed at the M-ART spike; the owner wants very detailed, stylish pixel art — D-10) with part slots: head, torso, arms, legs/wheel, tail/wings/cloak, accessory.
- **Animations** are authored once as part poses per frame and applied to every character.
- **A character** is parts + a palette ramp + signature animations.
- **Pipeline:** parts are generated by code in `assets-src/` with a master palette. `pnpm sprites` composes them into runtime sprite sheets in `resources/characters/<id>/` — the same pack format imported skins use.
- **Gate:** `art-director` accepts every character on screenshots over light and dark wallpapers.
- **Order:** rig + 3 characters (M-ART: maid, kitsune, goth), +3 (M3), +5 (M5) — 11 in total (D-15).

## Alternatives considered
- Hand-drawn per character (Aseprite): best quality but too much work. A hybrid with hand-drawn key parts was considered and rejected: the owner does not draw and there is no artist (D-11). Quality comes from code techniques instead: authored pixel masks for faces, selective outlines, manual AA, secondary motion (SPEC §5.2).
- AI-generated sprites: frames come out inconsistent and licensing is unclear. Use them as references only.
- One character only: weaker product (the owner rejected it, D-4).

## Consequences
- Positive: a new animation is one pose file for all characters; consistent style; deterministic, reviewable assets.
- Negative: the rig limits silhouettes (wheel, wings and cloak need slot variants); tooling work up front.
- Follow-ups: ART-BIBLE in `docs/art/`, `/sprite` and `/new-character` skills.
