## Acceptance criteria (each is a test, capture, perf number or owner look)
1. Core: `step(state, event, now)` pure; same seed + events → byte-identical effect log (replay test, 1 h simulated);
   coverage `src/core` ≥ 90 % (`pnpm test:coverage`). (A)
2. Walk: on-screen speed = `WALK_TRAVEL.pxPerSecond × scale` device px/s exactly; stride-locked steps; facing from the
   travel direction, `turn` forward before and reversed after; left = runtime mirror (unit tests on `shared/motion.ts`
   + core) and no visible foot skate (owner, real overlay). (A + O)
3. Surfaces: stands/walks/sits on the taskbar edge and on visible window top edges; falls within ≤ 250 ms when its
   window moves, minimises or closes (S4 event path) — core tests + owner check. Desktop-only layer = floor only. (A + O)
4. Drag 1:1, fling with inertia, wall bounce, `land` on the first surface crossed (core tests on closed-form paths);
   capture series light + dark. (A)
5. Cursor: startle on a sharp pass, petting by circling, poke on click (core gesture tests); cooldowns hold (throttle
   tests); none fire in `hidden`/`sleep` except wake rules. (A)
6. Sleep after `USER_IDLE_SLEEP_MS` of user idle, on lock/suspend; wakes on activity; stage ≤ 2 fps while asleep. (A)
7. Switch from tray, radial menu and hotkey: `switch_out` (walk off ≤ 2 s or poof) → `switch_in` at the same spot;
   drag interrupts; old atlas destroyed (texture-count test); active character and per-character mood survive a restart
   (settings + DB tests). (A + O)
8. Radial menu (UI-GUIDE §3) works by mouse and keyboard, screenshots light/dark theme × light/dark wallpaper at
   100 % / 125 %, ui-reviewer ✅. (A + O)
9. `pnpm perf` ×8 in budget: CPU < 2 %, private-bytes sum avg ≤ 280 MB (behaviour live, seeded); compat-mode walk CPU
   reported (ADR 007 obligation). (A)
10. README GIF of a walking character (`pnpm showcase`), owner ✅; packaged smoke look ✅. (A + O)

## Design
### Core (`src/core/`, layout per SPEC §11; pure, seeded, no timers)
- **State** `CoreState = { rng, character: { id, anims, idle }, world, pos: { surface, x, y }, facing: 'left'|'right',
  behavior, mood, throttle, cursor: { last, trail ≤ CURSOR_TRAIL.samples }, recent, hitThrough, wakeAt }`. Units:
  overlay DIP, `x` = foot pivot, `y` = surface top. `idle` is derived once by `toCharacterRef` (sole `no-idle` source).
- **Surface** = `{ kind: 'floor' } | { kind: 'window_top'; id: WindowId; left; right; y }` (union ready for
  `window_side | screen_edge` in M1b). `surfaces/visibleTops(rects front→back, workArea, sprite)` keeps only top-edge
  segments not covered by windows above, inside the work area, with sprite headroom, ≥ `SURFACE_MIN_WIDTH_ART` wide.
- **Behavior** (discriminated union, each with `since`/`until`; `until: number` for walk, turn, react, land, fall,
  switch_*; `number | null` for idle, sit_edge, activity, drag, menu, hidden, sleep; `react.resume` = a resting state
  without times, stamped on resume — walk/turn are re-planned, not resumed): `idle{anim}` · `turn{dir, then}` ·
  `walk{dir, x0, x1, startAt, arriveAt}` · `sit_edge` · `activity{id}` · `react{reaction, resume}` · `drag` ·
  `fall{path}` · `land` · `sleep` · `menu` (attending, front) · `switch_out{mode, to}` · `switch_in` · `hidden`.
- **Events**: `tick` · `world{workArea, windows[], scale, scaleFactor, layer}` · `input{…}` (pointer sample, leave,
  click, drag-start, drag-end{x, y, vx, vy}, context-menu{x, y}) · `user-idle{idleMs}` · `power{lock|unlock|suspend|resume}` ·
  `visibility{shown}` · `switch{to, mood}` · `character-loaded{id, ok}` · `menu-closed`.
- **Effects**: `Show{anim, facing, playback: fwd|rev, motion}` (motion = `still{x,y}` | `walk{x0, dir, steps, stepDip}`
  | `path{segments}`) · `Fx{mark, untilMs}` · `SetHitThrough` · `OpenMenu{x, y}` · `LoadCharacter{id}` ·
  `CommitSwitch{id}` · `PersistMood{id, mood, affinity}` · `PersistActive{id}` · `SetSensing{desktop: off|slow|fast,
  idle: slow|fast}`. `wakeAt` replaces a `Schedule` effect (F2).
- **Priorities** (`behavior/priorities.ts`, numbers in `content/behavior.ts`, SPEC §4.1): drag 100 > hidden 95 >
  switch 92 > cursor 55 > sleep 40 > activity 10. Rule: an event preempts iff its priority > current; equal → dedup
  queue (one pending per kind, newest wins); `hidden` drops all reactions and lines. `menu` sits at 60 (cursor
  reactions wait; drag still wins).
- **Throttle** (`throttle.ts`, needed by M4): per-reaction cooldown, global ≤ 1 unsolicited line / 10 min, quiet-hours
  window (default none), dedup queue — built and tested now; M1 uses it for cursor reactions and activity picks.
- **Physics** (`physics.ts`): ballistic closed form `p(t) = p0 + v t + ½ g t²` (gravity, restitution, fling clamp in
  `content/physics.ts`, in art px/s² × art-px-DIP so feel is size-independent). Path = segments split at wall/ceiling
  bounces; landing = first descending crossing of a surface whose span holds x (solved per surface). Landing speed >
  `HARD_LANDING` → `land` + sweat Fx; else `land` short. Window moved/closed under a standing character → `fall`
  from rest. Same pure sampler (`shared/motion.ts`) is used by the renderer, so both agree on every point.
- **Travel (ADR 010, q34)**: distance quantised to whole strides: `stepDip = WALK_TRAVEL.pxPerFrame × scale /
  scaleFactor`, `steps = round(d / stepDip)`, `arriveAt = start + steps × 1000 / WALK_TRAVEL.fps`. Facing = sign(dx);
  sequence `turn` (fwd, mirrored if left) → `walk` → `turn` (rev) → front idle. Renderer moves the sprite one step per
  walk frame from elapsed time (`floor(elapsed × fps)`), never by interpolation → planted foot does not skate.
  Integrity test: every built-in `walk.fps == WALK_TRAVEL.fps`.
- **Activities** (`activities.ts`): weighted pick with recency penalty (`RECENT_PENALTY`, last N), conditions
  `where` (surface kinds), mood band, time of day (from `now` + tz offset passed in `world`), min/max duration, cooldown.
  M1 shared set (existing anims only): stand (`idle_a`), fidget (`idle_b`), stroll (walk to a random reachable x),
  sit on edge (`sit_edge`, window_top only — on the floor the legs would fall under the work area), think, wave.
- **Cursor** (`cursor.ts`): samples (main receipt time) only while near; startle = speed > `STARTLE_DIP_S` within
  `NEAR_DIP`; petting = accumulated angle around the body centre ≥ `PET_TURNS` within `PET_WINDOW_MS` while over the
  sprite; poke = click (`happy|wave` per persona; ≥ 3 pokes in `POKE_WINDOW_MS` → `worried`). Petting raises mood.
- **Sleep**: `user-idle ≥ USER_IDLE_SLEEP_MS` or lock/suspend → `sleep` + Zzz Fx; wake on idle reset / unlock /
  click (poke wakes with `startle`). **Mood** (`mood.ts`): analytic decay toward 50 from `updatedAt`, `+PET_MOOD`,
  `+PET_AFFINITY`; bands low/mid/high bias activity weights only (§4.5, no penalties).
- **Switch** (`switch.ts`, D-8): walk off if the nearest screen edge is ≤ `SWITCH_WALK_MAX_MS` away, else poof (smoke
  Fx) → wait `character-loaded` (timeout `SWITCH_LOAD_TIMEOUT_MS` → stay, log) → `CommitSwitch` → `switch_in` at the
  same spot (walks in from that edge or poof). Drag during the transition commits at once, new character in the hand.
  Mood of the old one persisted before commit; new one arrives with its stored mood.

### Content (`src/content/`, owner of numbers: persona-designer + owner by eye)
`behavior.ts` (priorities, durations, sleep threshold, switch numbers) · `physics.ts` · `cursor.ts` · `mood.ts` ·
`desktop.ts` (poll intervals, min surface width) · `activities.ts` (shared set) · `characters/<id>/activities.ts`
(weights per persona, poke reaction, optional reaction override e.g. vampire startle → `cloak_hide`) · `stage.ts`
keeps `WALK_TRAVEL`, drops `CoreAnimation`/`CLICK_REACTIONS` (moved).

### IPC (`src/shared/ipc.ts`; `/ipc-channel`; contract tests both ends)
- `stage:input` → union: `pointer{x,y}` (≤ 30 Hz, only within `NEAR_DIP`) · `pointer-leave` · `click` · `drag-start` ·
  `drag-end{x,y,vx,vy}` (finite, |x|,|y| ≤ 16384, |v| ≤ `LIMITS.flingMax`) · `context-menu`.
- `stage:frame-state` (new event, main → stage, SPEC §3.2 name): `{ seq, key, anim, facing, playback, motion, fx[] }`;
  idempotent snapshot (a reload re-applies it).
- `stage:loaded` (new send): `{ key, ok }` after an atlas is ready or failed.
- `stage:characters`: + per-animation `fx` anchors (int frame px per frame), + `fx` atlas `{url, marks}`, entries tagged
  `active | incoming`. Per-animation `anchor` already crosses IPC (MA-30) — the renderer applies it now.
- `menu:state` (event: items with enabled/reason, characters `{key, nameKey, thumb: atlas url + rect}`, current,
  switching) · `menu:action` (send: `switch{key}` | `hide` | `settings` | `close`). Window role `menu` (WINDOW_ROLES).

### Main
- `sensors/desktop.ts` + `desktop.win32.ts` (ADR 014): rects validated (finite, ≤ 64 windows, ≥ 1 px), own windows and
  shell classes dropped, physical → DIP, opaque ids; cadence from `SetSensing` (fast only while on a window; off in
  sleep/hidden/desktop layer). `sensors/idle.ts`: `powerMonitor.getSystemIdleTime()` (s) every `IDLE_POLL_MS.slow`
  (15 s) awake / `.fast` (1 s) asleep; `lock-screen`/`unlock-screen`/`suspend`/`resume`.
- `scheduler/` one timer to `wakeAt`. `StageController` interprets every effect (fixes the dropped `PlayAnimation`),
  pushes `stage:frame-state`, owns switch loading and the menu window.
- Storage (ADR 008): **electron-store** `settings.ts` (zod) = `activeCharacter`, `sizePreset`, `layer`;
  **SQLite** `storage/db.ts` (`node:sqlite`, WAL, `transaction()` wrapper, `user_version`) + migration `001-character-state`
  (`character_state(character_id TEXT PK, mood INT, affinity INT, updated_at INT)`), fixture `tests/fixtures/db/v0`
  (empty) → v1; writes debounced (`MOOD_FLUSH_MS`) + on switch and quit. Mood is per character in SQLite as SPEC §4.5
  says; electron-store only for settings.
- Tray (§8): show/hide, **character ▸ radio list (i18n names)**, chat, settings, layer, size, quiet mode (disabled,
  "M3"), quit; icon = active character head. Hotkey "next character" (Q5).
- `app-protocol.ts`: `app://characters/fx/…` (registered FX files only), `font/woff2`+`font/ttf` MIME; M0 leftovers
  **L2** CSP as response header for `app://renderer`, **L3** junction/realpath check. CSP `font-src 'self'`
  (`tools/lib/csp.ts`), `build.assetsInlineLimit` callback → `false` for fonts. `extraResources` ships `fx/**`.

### Renderer
- Stage (Pixi, no UI text, no fonts): split `main.ts` into `actor.ts`, `motion.ts` (applies `stage:frame-state` via
  `shared/motion.ts`), `fx.ts`, `input.ts`. Frame timers for idle/sleep (≤ 6 fps; sleep 2 fps); walk advances on
  frame-locked steps (render 10 fps); ticker (rAF, own throttle, ADR 007) only during `path` and drag. Per-anim
  `anchor` and FX anchors applied; reverse playback for `turn`. Switch: build incoming actor, report `stage:loaded`,
  destroy old textures/sources after `CommitSwitch`.
- Menu (React + CSS Modules, `tokens.css`, Tiny5 + Rubik; Press Start 2P waits for the M2 bubble): radial items
  (switch character → gallery sub-panel of 72-px cells, quiet (disabled + reason), settings, hide), `radialLayout()`
  on the arc that fits the work area, `role="menu"`, arrows/Enter/Esc, focus ring, reduced motion, forced colours.
  States: open · gallery · switching (items disabled, current marked) · pack failed (cell ✗ + reason).

### Checks (a)–(h)
- (a) decisions all in core (above); main only senses and interprets. (b) numbers in the content files listed.
- (c) IPC above; preloads `stage.ts` (+`sendInput` union, `onFrameState`, `reportLoaded`), new `menu.ts`
  (`onState`, `act`); main validates with zod + sender role + URL. (d) DB: migration 001 + fixture (above).
- (e) untrusted: window rects (validated numbers, no titles), renderer input (zod bounds), pack manifests (existing
  schema + new `fx` anchors inside the frame). Nothing reaches a prompt in M1.
- (f) perf: no new resident window (menu destroyed on close); sensors event-driven or ≤ 1 Hz on the floor; walk renders
  at 10 fps; SQLite ≈ +11.6 MB RSS (S2) and koffi are the main RAM risks vs **maid 263.7 MB** → measured after M1-19/20.
- (g) i18n uk + en: `tray.character`, `tray.quiet`, `tray.quiet.soon`, `character.<id>.name` ×8,
  `character.<id>.trait` ×8, `menu.label`, `menu.switch`, `menu.quiet`, `menu.quiet.soon`, `menu.settings`,
  `menu.hide`, `menu.close`, `menu.gallery.label`, `menu.pack.failed`, `hotkey.next.conflict`.
- (h) animations: the 16 existing + FX marks (Zzz, heart, sweat, !, ?, smoke). No new rig pose, except the optional
  vampire `cloak_hide` (M1-32, Q3).

flat across all runs; the whole spread is the gpu-process, which settles on one of two plateaus: ≈ 87.5 MB
(sum ≈ 216) or ≈ 132.5 MB (sum ≈ 259–263); Δ ≈ 45 MB. Runs at 113–123 MB switched plateau mid-window. The low
plateau hit witch #1, maid #3 and ronin, so both maid and witch land on either one. All 8 atlases are 1008×336

Radeon iGPU allocates an extra ≈ 45 MB buffer pool (swap-chain or compositor surfaces) in some launches. For budget
work, read the high plateau (≈ 262 MB avg) as the baseline: 18 MB headroom, not 64.

## M1-02 result (2026-11-28) — spike S4 passes, mode (a) event hook
Harness `src/main/dev/desktop-spike.ts` (dev-only, `--desktop-spike=<bench|load|poll|hook> --desktop-spike-out=<dir>`;
deleted by M1-20). It lists windows with koffi → `EnumWindows` + the ADR 014 filters + DWM bounds +
`screen.screenToDipRect`, with no titles and no process access. Packaged runs used a local, uncommitted gate patch
(`|| process.env.PIXMATES_SPIKE` on the dev-only block) on a fresh `pnpm dist:dir` (fuses on, asar). Then
`pnpm perf -- --skip-build` (30 s + 120 s, AC) ran with the spike env set. Typing/drag load came from a scratch
process with its own top-most EDIT window that types into itself (20 chars/s, `EM_REPLACESEL`) or moves itself
(60 Hz). It injects no input into other apps.
- **Load in the packaged build: OK.** electron-builder unpacks `@koromix/koffi-win32-x64/win32_x64/koffi.node` (smart
  unpack, now also explicit `asarUnpack`). `koffi.load` + declarations take 1.3–2.5 ms.
- **WinEvent hook in the packaged build: OK.** `SetWinEventHook(OUTOFCONTEXT | SKIPOWNPROCESS)`, 5 narrow ranges.
  Callbacks arrive on the Electron main thread's message loop (dev and packaged). Idle desktop: 0 events in 120 s.
- **Enumeration, 175 top-level handles (4 kept):** tight loop ×500: median 0.25 ms, p95 0.49 ms. Spaced 1 Hz:
  median 0.67–0.82 ms, p95 1.1–1.8 ms. Worst case, every probe on every handle: median 1.97 ms = 11 µs/handle, so
  40 windows ≈ 0.45 ms + `EnumWindows`. **< 2 ms ✅**
- **CPU while typing 115 s** (4115 events = 36/s: caret show/hide/location; ≈ 5 µs JS per callback):

| off + typing ×2 | 0.62 / 0.61 | — |

- `pnpm perf` within budget in all 31 runs (CPU 0.21–0.76 %, private avg 251–268 MB).

**Verdict: ADR 014 rule (a) met. Chosen mode is the WinEvent hook, plus a slow refresh.** For M1-20 (not decided
here, architect/owner):
- Cursor motion was not measured, because it would move the owner's mouse. `OBJID_CURSOR` location events arrive
  for every mouse move, so they may add ≈ 2–3× the typing event rate. Check this in the M1-20 perf spot run.
  Option to evaluate: hook `EVENT_OBJECT_LOCATIONCHANGE` only for the pid of the window under the character
  (`GetWindowThreadProcessId`, no process handle).
- Keep the reduced koffi sync blocks.
- Optionally exclude koffi's sources/docs/headers (≈ 1.7 MB) from app.asar.
- koffi **has** an `install` script (`cnoke --prebuild`: test-load the prebuilt binary, else CMake build). It is
  denied in `allowBuilds`, because the binary comes from the script-free platform package.

**Security carry-overs for M1-20 `sensors/desktop.win32.ts`** (electron-security-reviewer on 7aaa9f3..9ce9a1e; M1
finding fixed: dev-only surfaces now behind a build-time gate, `src/main/app/dev-build.ts`):
- **m1 DLL planting:** load `user32.dll` / `dwmapi.dll` by absolute path (`%SystemRoot%\System32\…`, from
  `process.env.SystemRoot` with a `C:\Windows` fallback), never a bare name: the per-user install dir is writable.
- **m2 asar integrity:** the unpacked `koffi.node` is not covered by asar integrity. koffi resolves the package
  directory `@koromix/koffi-win32-x64` (its `package.json` `main` → `index.js` → `require('./win32_x64/koffi.node')`),
  so `package.json` + `index.js` can stay inside app.asar (asar fs, integrity-covered) and only `koffi.node` needs
  unpacking; `koffi.lib` is a link-time import lib, not needed at runtime. Narrow `asarUnpack` to
  `node_modules/@koromix/koffi-win32-x64/win32_x64/koffi.node` and confirm with a packaged run. Plan Authenticode
  signing (exe + `koffi.node`, M6 packaging) and note it in ADR 014 (done).
- **m3 callback lifetime:** don't `koffi.unregister` the WinEvent callback right after `UnhookWinEvent`: queued
  out-of-context events may still be dispatched to it. Keep the registered callback until exit (or defer the
  unregister past the message queue drain).
