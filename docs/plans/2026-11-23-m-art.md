## Phase 2 — fit and decisions
- **Scope check.** Fits the M-ART row (SPEC §12, edited to the D-15 trio in v1.9). No behaviour: the stage plays only the active character's `idle_a` loop (D-8; behaviour = M1). Persona, lines, display names, signature animations, FX playback on stage and the tray character switch → M1 (switch needs `switch_out/in`, persistence and i18n names, SPEC §4.4). Review of the other two uses `--character=` and the dev lineup.
- **Frame 48 × H with headroom (ADR 009).** Width 48. H = the smallest of 52/56/60 such that every frame of every slot variant keeps rows 0 transparent (and ≥ 1 clear row above the tallest point: kitsune ears at the happy apex); provisional **48 × 56**, fixed in MA-23 by measurement. Feet stay on the same row, so the extra rows are pure headroom.
- **Sizing must not shrink.** `computeScale` today divides by `frameH`; with H = 56 the M preset would drop from ×4 to ×3. New optional manifest field `scaleRef` (px, default `frameSize.h`) = the standing-figure height used for sizing; built-ins write 48, so S/M/L stay ×3/×4/×5 (ADR 009). The `maxFraction` clamp keeps using the full frame height. Pure change in `src/core/scale.ts` (`refH` next to `frameH`).
- **Per-animation `anchor` (optional).** `sit_edge` (and `hang` in M1) pivot on the seat/hands, not the feet. The pose sets a `seat` joint and the builder emits `animations.sit_edge.anchor`. Manifest-only in M-ART (validated); the IPC payload carries it from M1, when surfaces exist. SPEC §5.1 edit after Q1 below.
- **Pack ids.** Built-ins are `pixmates.<id>` (rules/characters.md: prefix reserved, imports cannot overwrite), folder = id: `resources/characters/pixmates.maid/`. `src/shared/pack.ts` gets `BUILTIN_PREFIX` + `builtinPackId(rosterId)`; content keeps roster ids (`DEFAULT_CHARACTER = 'maid'`); the registry accepts only `pixmates.*` folders in packaged builds. `spike-*` stay dev-only until deleted in MA-31.
- **Animation set: the 15 are confirmed** (`idle_a`, `idle_b`, `walk`, `sit_edge`, `sleep`, `drag`, `fall`, `land`, `talk`, `think`, `happy`, `worried`, `wave`, `petted`, `startle`): each is consumed by M1 (states, drag/fling, sleep, cursor petting, startle) or M2 (talk + the 4 emotion bodies), and authoring them now validates the rig on 3 bodies before M1 builds on it. If art rounds overrun, drop in this order with fallbacks: `idle_b`→`idle_a`, `petted`→`happy`, `startle`→`worried`. Fallbacks shipped: `run`,`climb`→`walk`; `hang`→`drag`; `peek`→`idle_a`; `react:*`,`activity:*`,`*`→`idle_a`.
- **Frame budget** (frames @ fps): idle_a 8@6, idle_b 12@6, walk 8@10, sit_edge 6@6, sleep 8@3, drag 4@8, fall 4@10, land 4@10, talk 6@8, think 8@6, happy 6@8, worried 8@6, wave 8@8, petted 8@8, startle 5@10 = 111 frames. ## Rig spec (written to `docs/art/RIG.md` in MA-20)
- **Coordinates:** 48-px units, origin = root at the feet (x 24 on a pixel boundary, feet row fixed); joints are integer offsets from their parent.
- **Joints:** root → hip → chest → neck → head → face; chest → shoulder L/R → hand L/R; hip → foot L/R; chest → back (tail/cloak); head → acc (ears/horns/clip); head → fx (mark anchor, emitted per animation for M1); hip → seat.
- **Slots and variants:** `head` (per character authored mask); `head_acc` `horns | fox_ears | clip` (antenna M3); `hair_back` `short | long` (chain); `torso`; `arms` mitten biped; `legs` `biped` (wheel M3 — contract only); `hem` `skirt | shorts` (chain lag); `back` `none | spade_tail | fox_tail` (cloak, wings M3+ — contract only); `neck_acc` `bow | choker | scarf`.
- **Body (`assets-src/characters/<id>/body.ts`):** joint rest offsets, chosen variants, ramps per material, part generators (procedural: cloth, back hair, fur, tail tube) and authored masks (head, fringe, horns/ears, shoes, bow/choker, face library).
- **Pose (`assets-src/rig/anims/<anim>.ts`, one file per animation, shared by all bodies):** per frame `{ root: {dx,dy}, joints?: Partial<Record<Joint,{dx,dy}>>, parts: { armL, armR, legs, hem? }` (variant ids e.g. `arm:swing_fwd`), `face: ExpressionId`, `squash: −2…+2` (whole rows inserted/removed under the chest, no resampling), `breath: 0|1` (sub-pixel chest colour shift), `order?: 'arms_front'|'arm_l_back'|…`, `impulse?: {x,y}` (chain kick) `}`. A body may override a pose only through a per-body `tweaks` table (offsets), never by forking the animation.
- **Composite order:** back → hair_back → legs/hem → torso → arms (by `order`) → head mask → head_acc → face layer → neck_acc; then outline, selective outline, AA, authored masks restored, rim (rules: passes run on the composite, so seams never show).
- **Frame names** `<character>/<anim>/<nn>` (sheets, tests, errors). The builder checks: palette-only px, row 0 transparent in every frame, frame counts = pose lengths, loops seamless (chain), atlas ≤ 1024², every manifest animation resolves.

## Face library (per character, `assets-src/characters/<id>/face.ts`)
- An expression = `{ eyes, brows?, mouth, cheeks }` masks on the face anchor; parts are reused across expressions, so a character authors ≈ 8 eye masks + 6 mouths, not 13 full faces.
- Expressions: `neutral`, `blink` (closed), `half` (half-lid, sleep-in/idle_b), `talk_a/b/c` (closed, small open, open «o»), `happy` (^^ eyes + open D-mouth with tongue), `worried` (raised inner brows, wavy small mouth), `think` (eyes glance up-side, flat side mouth), `sleep` (closed, small «o»), `startle` (>< eyes + «o»), `petted` (^^ + strong blush), `wince` (drag/fall: one eye squeezed).
- A test fails the build if a character misses any expression a pose references; face px never cover hair (ART-BIBLE §11).
