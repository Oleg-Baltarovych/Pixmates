# Art pipeline rules — SPEC §5.2; ADR 004, 005

- The source of style is `docs/art/` (art bible, master palette, rig spec). A sprite that contradicts it is wrong even if it "looks fine".
- Built-in characters = shared 32×32 rig + per-character parts in slots + palette ramp + signature animations, all generated by code in `assets-src/`. Shared animations are authored once in `assets-src/rig/` and must work on every body type.
- Style:
  - coloured dark outline (never `#000`), with a light rim where needed for dark wallpapers;
  - consistent light from top-left;
  - hue-shifted ramps;
  - no pillow shading;
  - readable on both white windows and dark IDEs.
- Animation: 6–12 fps; anticipation, squash on landing, overlapping motion on tails, cloaks and hair; seamless loops; emotions readable in 2–4 frames.
- Pivot at the feet (`anchor: { x: 0.5, y: 1 }`); frame names `<character>/<anim>/<nn>`.
- `pnpm sprites` is deterministic: same input → same bytes (it prints hashes). Never edit `resources/characters/`; it is generated.
- Originality (ADR 005): no costumes, symbols or colour schemes that make a character read as a protected one. AI-generated images are references only.
- Third-party assets: commercial use allowed, license kept, entry in `docs/art/LICENSES.md`. Unknown license = do not use.
- After a visual change, run `/sprite` steps 4–6 (sheet, stage screenshots on light and dark wallpapers, `art-director`).
