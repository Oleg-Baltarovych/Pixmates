# Art pipeline rules — SPEC §5.2; ADR 004, 005

- The source of style is `docs/art/` (art bible, master palette, rig spec). A sprite that contradicts it is wrong even if it "looks fine".
- Detail first (D-10): very detailed, stylish pixel art; frame 48 or 64 px (fixed at M-ART), rich materials and secondary details (fabric folds, highlights, accessories) without losing the silhouette.
- Style = pixel anime (D-13, SPEC §5.2): chibi ~2–2.5 heads; big expressive eyes (~⅓ of face height, gradient coloured iris, 2 highlights, defined lashes) carry the emotion; cel shading (2–3 tones, hard terminator) or anime soft per ADR 009; hair in pointed clumps with an "angel ring" shine band; anime emotion marks as FX (sweat drop, anger vein, blush hatching, ^^ / >< eyes); non-human characters as anime mascots (screen/flame eyes, rounder forms). Style is not IP — originality (ADR 005) is checked on every review.
- All art by code, quality maxed (D-11, SPEC §5.2):
  - faces and key details as authored pixel masks (one face layer per emotion); procedural generators only for materials (cloth, metal, stone, fur);
  - 5–7-tone hue-shifted ramps per material; selective outline (coloured, lighter on the lit side); rim light for dark wallpapers; manual AA on curves; dithering only as texture;
  - secondary motion (hair, tails, cloaks, ribbons) simulated per frame and quantized to pixels; squash & stretch, anticipation, follow-through; breathing idle; sub-pixel animation (colour shifts) for small motions;
  - "good enough" is not the bar: each character passes up to 3 art-director rounds and the owner's sign-off against the ART-BIBLE beauty checklist.
- Built-in characters = shared rig + per-character parts in slots + palette ramp + signature animations, all generated by code in `assets-src/`. Shared animations are authored once in `assets-src/rig/` and must work on every body type.
- Style:
  - coloured dark outline (never `#000`), with a light rim where needed for dark wallpapers;
  - consistent light from top-left;
  - hue-shifted ramps;
  - no pillow shading;
  - readable on both white windows and dark IDEs.
- Animation: 6–12 fps; anticipation, squash on landing, overlapping motion on tails, cloaks and hair; seamless loops; emotions readable in 2–4 frames.
- Pivot at the feet (`anchor: { x: 0.5, y: 1 }`); frame names `<character>/<anim>/<nn>`.
- `pnpm sprites` is deterministic: same input → same bytes (it prints hashes). Never edit `resources/characters/`; it is generated.
- Originality (ADR 005): no costumes, symbols or colour schemes that make a character read as a protected one. AI-generated images are references only.
- Third-party assets: commercial use allowed, license kept, entry in `docs/art/LICENSES.md`. Unknown license = do not use.
- After a visual change, run `/sprite` steps 4–6 (sheet, stage screenshots on light and dark wallpapers, `art-director`).
